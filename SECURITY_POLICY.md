# Security Policy

This is a PUBLIC repository. Treat all Git history as permanently retrievable.

Permanent rules:
NO_SECRETS_IN_GIT
NO_CERTIFICATES_IN_GIT
NO_BROKER_ACCOUNT_IN_GIT
NO_PASSWORDS_IN_GIT
NO_TOKENS_IN_GIT
NO_COOKIES_IN_GIT
NO_PRIVATE_KEYS_IN_GIT
NO_PROPRIETARY_SDK_IN_GIT
NO_LICENSE_RESTRICTED_RAW_DATA_IN_GIT
NO_PAID_DATA_IN_GIT

UNKNOWN = DENY.
